# 📖 Overview

JobBridge is a full-stack recruitment platform designed to simplify the hiring process for both employers and job seekers. The application provides a seamless experience for posting jobs, searching opportunities, applying online, and managing applications through dedicated dashboards.

The project was developed as a **Final Year BCA Major Project** using the **MERN Stack** and follows modern web development practices including REST APIs, JWT authentication, responsive UI, and MongoDB database management.

# 🚀 Installation

## Clone Repository

```bash
git clone https://github.com/Growwithtahira/JobBridge.git
```

Navigate to project

```bash
cd JobBridge
```

---

## Install Frontend

```bash
cd frontend
npm install
```

---

## Install Backend

```bash
cd backend
npm install
```

---

## Environment Variables

Create a `.env` file inside the backend folder.

```env
PORT=5000

MONGO_URI=your_mongodb_connection_string

JWT_SECRET=your_secret_key

CLIENT_URL=http://localhost:3000
```

---

## Start Backend

```bash
npm run dev
```

---

## Start Frontend

```bash
npm start
```
